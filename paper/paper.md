# Summary

Genome-scale CRISPR-Cas9 loss-of-function screens generated by the Cancer Dependency Map (DepMap) [@Tsherniak:2017; @Meyers:2017; @Dempster:2021] provide a widely used reference for prioritizing candidate cancer vulnerabilities, separating pan-cancer essentials from lineage-restricted dependencies, and mapping functional gene relationships via co-dependency. `crispr-score-analyzer` is an open-source, MIT-licensed Python software package that exposes a Streamlit-free computational library, a reproducible command-line interface (`crispr-score-analyzer`), and an interactive browser frontend (`app.py`) for cohort-scoped CRISPR gene essentiality and co-dependency analysis. Built on NumPy, pandas, Plotly, Pillow, and Kaleido, the core library validates custom UTF-8 CRISPR score matrices or reads compact DepMap Chronos matrices, resolves legacy human gene symbols offline against 40,402 unambiguous HGNC alias mappings [@Seal:2023], computes cohort-wide essentiality rankings and lineage-preference profiles, executes chunked `float64` pairwise-complete Pearson or Spearman genome-wide co-dependency scans without SciPy, renders colorblind-safe Nature Publishing Group (NPG) and ColorBrewer `RdBu` figures, and exports white-paper vector PDF/SVG/300-DPI PNG figures alongside SHA-256 ZIP provenance bundles.

# Statement of need

In routine oncology target-prioritization workflows—such as evaluating 5–50 candidate hits from RNA-seq, proteomics, or focused genetic screens against DepMap Chronos scores—wet-lab and computational researchers repeatedly encounter four workflow bottlenecks:

1. **Multi-gene cohort context:** Placing a panel of candidate genes together along a cohort-wide essentiality curve, or overlaying prioritized hits onto a pathway background set, typically requires repetitive single-gene portal lookups or bespoke scripts.
2. **Separating pan-cancer essentiality from lineage-selective vulnerability:** Pan-cancer mean scores often dilute tissue- or subtype-restricted dependencies (such as `SOX10` in skin or `ESR1` in ER-positive breast models), whereas selecting concrete sensitive and resistant cell lines for wet-lab validation requires cross-referencing lineage summaries against individual model identifiers.
3. **Cohort-scoped genome-wide co-dependency scanning:** Pan-cancer co-dependency correlations mix pathway co-essentiality with inter-lineage variance; restricting a genome-wide scan to one lineage or custom cohort while tracking exact pairwise shared cell-line counts (`n_shared`) usually demands multi-step manual setup or custom code.
4. **Reproducible custom-matrix validation and publication export:** Analyzing unpublished or internal CRISPR score matrices alongside public reference cohorts requires strict column validation, explicit handling of missing/non-numeric/infinite values, editable vector figures, and machine-readable metadata recording exact inputs, software versions, and checksums.

`crispr-score-analyzer` addresses these needs through a single, consistently tested Python codebase usable interactively in a browser, programmatically in notebooks and pipelines, or headlessly from the command line.

# State of the field

Existing tools serve complementary parts of the DepMap ecosystem:

- The **DepMap Portal** [@Tsherniak:2017; @Dempster:2021] provides authoritative data hosting and rich single-gene exploration, but multi-gene cohort ranking curves, live single-lineage genome-wide co-dependency scans, full custom CSV matrix uploads with column diagnostics, and bundled SHA-256 provenance archives are not unified in one lightweight workflow.
- **shinyDepMap** [@Shimada:2021] offers interactive efficacy-versus-selectivity exploration and pan-cancer connectivity clusters in R/Shiny, but does not provide a pip-installable Python library/CLI, custom CRISPR score matrix uploads, offline batch HGNC alias resolution, or cohort-scoped genome-wide scans.
- **Co-essentiality atlases** [@Wainberg:2021] provide precomputed pan-cancer modules rather than interactive cohort-restricted re-computation on arbitrary cell-line subsets or user matrices.
- The Bioconductor **`depmap` R package** [@Killian:2021] streamlines downloading and tidying DepMap releases inside R via `ExperimentHub`, but leaves ranking, lineage-preference summarization, cohort-scoped co-dependency computation, publication plotting, and interactive UI assembly to end-user R scripts.

Rather than extending an R-only data accessor or a hosted portal backend outside external contributor control, we built a dedicated, zero-SciPy Python package (`crispr_score_analyzer`) paired with a thin CLI and Streamlit frontend so Python bioinformaticians and non-coding wet-lab biologists share identical validated analytical kernels.

# Software design

`crispr-score-analyzer` enforces a strict architectural separation between reusable computation and interactive presentation:

- **Core analytical engine (`crispr_score_analyzer.analysis_core`):** Implements duplicate-preserving UTF-8 CSV loading (`read_score_csv`), strict DepMap-style `SYMBOL (Entrez ID)` auto-detection with explicit manual column override for plain-symbol matrices, exclusion and logging of ambiguous duplicate symbols (`diagnostics.csv`), deterministic ascending mean-score ranking with missingness accounting (`analyze_dataset`), offline HGNC alias resolution (`load_gene_aliases`, `resolve_gene_list`), lineage-preference summaries (`lineage_preference`), paired sensitive/resistant model extraction (`top_cell_lines`), and self-contained ZIP provenance packaging (`make_analysis_bundle`).
- **Vectorized co-dependency engine (`crispr_score_analyzer.codependency`):** Computes exact pairwise-complete Pearson *r* and average-rank Spearman *ρ* correlations across 18,433+ partner genes in 2,048-column `float64` chunks (`genomewide_codependency`) using only NumPy and pandas, enforcing minimum shared sample thresholds (`min_shared = min(10, max(3, n_valid_query))`) and non-zero variance guards, alongside lineage-colored pairwise scatter builders (`gene_pair_scatter_frame`, `create_gene_pair_scatter`).
- **Streamlit-free publication plotting & export (`crispr_score_analyzer.plotting`, `crispr_score_analyzer.figure_export`):** Exposes reusable Plotly builders using colorblind-safe Nature Publishing Group (NPG) categorical hues and a 7-stop ColorBrewer `RdBu` diverging scale across light and charcoal-dark themes (\autoref{fig:overview}). All vector exports convert WebGL scatter traces (`Scattergl`) to pure SVG/PDF vector paths onto white paper and embed explicit 300-DPI metadata in raster PNG exports, keyed by SHA-256 figure fingerprints.
- **CLI & interactive web layer (`crispr_score_analyzer.cli`, `app.py`):** Exposes reproducible `info`, `rank`, `codep`, and `app` subcommands on custom CSV or `.npz` inputs, while `app.py` provides a bilingual (English/Chinese) four-module Streamlit workspace with draft/committed state isolation and native text inputs with deterministic prefix/alias filtering.
- **Software/data license separation:** Application source code and the CC0/public-domain HGNC alias table are distributed under the MIT license. The optional DepMap Public 26Q3 binary matrix (`data/depmap_chronos.npz`, 1,361 cell lines × 18,434 genes across 30 Oncotree lineages) is governed separately by Broad Institute DepMap non-commercial terms (`data/DEPMAP_TERMS.md`) and is strictly excluded from Python wheels, source distributions, and MIT release archives. All automated unit, CLI, plotting, and UI tests execute offline on small synthetic fixtures.

`crispr-score-analyzer` is actively maintained and deployed as a public browser service (`https://crispr-score-analyzer-szbl-denglab.streamlit.app/`) alongside versioned Zenodo software archives (`v1.0.0` through `v1.2.0`; concept DOI `10.5281/zenodo.19607602`) and supports routine candidate gene essentiality triage, lineage-restricted vulnerability screening, and sensitive/resistant cell-line selection in cancer biology workflows at the Institute of Molecular Physiology, Shenzhen Bay Laboratory. Across benchmark evaluations on DepMap Public 26Q3, the software recovers canonical pan-cancer essentials (`MYC`, `PLK1`), lineage-selective vulnerabilities (`SOX10` in skin, `ESR1` in ER-positive breast models), the pan-cancer inverse `MDM2`–`TP53` dependency axis (`r = -0.702`), and stronger within-lineage `BRAF`–`MAPK1` co-dependency in skin cancer models (`r = +0.798` vs. `+0.644` pan-cancer), while keeping every numerical output explicitly framed as an exploratory descriptive summary paired with downloadable provenance.
